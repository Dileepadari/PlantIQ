Data path

The ESP32 samples all four sensors on a fixed interval. Readings go to ThingSpeak over MQTT, which is what every chart on this site reads back. The same readings are pushed to an OM2M middlenode over HTTP.

When a value crosses the threshold stored for the selected plant, the firmware POSTs an alert to /api/alerts on this server, which is what fills the Alerts page.
