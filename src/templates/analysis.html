How to read this

PlantIQ watches temperature, humidity, soil moisture, light, CO2 and volatile organic compounds. Each plant in the database carries a safe range for those six values. A reading inside the range is marked Healthy; a reading outside it is marked Out of range.

A rising VOC level alongside a temperature or humidity shift is the pattern that usually precedes a pathogen attack, which is what the project set out to catch early. When the firmware sees a value cross a threshold it posts an alert, which shows up on the Alerts page.
